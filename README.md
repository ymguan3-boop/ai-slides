## 手機遙控

兩份簡報都支援 QR Code 手機遙控（技能：[slides-qr-remote](https://github.com/ymguan3-boop/audit-assistant-skills/tree/main/skills/slides-qr-remote)，Ably Realtime 同步）。

- 五結防潮閘門簡報：第 1 頁與最後一頁右上角有 QR Code，按 `H` 的說明面板也有。手機可換頁、跳頁、播放／暫停影片、開關字幕、投影講者備註、開關 H 說明，並在手機上顯示本頁講稿。
- 道路簡報：結束頁有 QR Code。

## 五結防潮閘門簡報操作

`→`／空白 下一步、`←` 上一頁、`N` 講者備註、`H` 說明與 QR、`F` 全螢幕、`M` 減少動態；影片頁空白鍵暫停、`C` 字幕、`R` 從頭。3D 模型頁在模型內操作時鍵盤歸模型，點模型外任一處即恢復換頁鍵。

## 內容與限制

- 五結防潮閘門簡報中的 3D 模型為靜態風險篩檢，不是正式水理模擬；官方 NLSC 3D 建物須連網載入，離線時顯示預錄畫面。
- 本倉庫不含原始工程報告、Word 說明書與證據包下載檔。
